# Индикатор Yandex.Disk на Vala

Панельный индикатор для демона `yandex-disk`: иконка состояния с анимацией
синхронизации, меню со статусом, размерами диска и последними синхронизированными
элементами, диалог настроек, экранные уведомления и действия для файловых
менеджеров.

Проект является переписанной с помощью нейросети версией индикатора
[yandex-disk-indicator](https://github.com/slytomcat/yandex-disk-indicator)

## Зависимости

Сборка:

    valac  pkg-config  libglib2.0-dev  libgtk-3-dev  libayatana-appindicator3-dev

Сборка `.deb` дополнительно:

    dpkg-dev  debhelper  fakeroot

Работа:

    yandex-disk (CLI-демон)  zenity  xclip

## Сборка и запуск

    make            # бинарник build/yandex-disk-indicator-vala
    make test       # тесты разбора вывода демона и конфигурационных файлов
    make stage      # бинарник и каталог данных в build/stage/usr
    make run        # запуск из дерева проекта, без установки в систему
    make clean      # удалить build/ (вместе с build/deb/) и usr/

`make run` передаёт индикатору переменную `YD_ROOT` с путём к каталогу данных,
поэтому иконки, `ya-setup` и переводы берутся из `build/stage`, а не из `/usr/share`.

В панели работает только один индикатор: экземпляр удерживает блокировку файла
`~/.config/yd-tools/yandex-disk-indicator.lock`, и второй запуск завершается
сообщением «Другой экземпляр индикатора уже запущен».

Переменная `INDICATOR_PKG` задаёт binding иконки в панели: по умолчанию
`ayatana-appindicator3-0.1`, вариант без префикса Ayatana — `appindicator3-0.1`
(namespace в Vala у них одинаковый):

    make INDICATOR_PKG=appindicator3-0.1

## Ключи командной строки

    -l, --log {10,20,30,40,50}   уровень журнала: 10 - все сообщения, 50 - только критические
    -c, --config path            добавить конфигурацию демона к списку наблюдаемых
    -r, --remove path            убрать конфигурацию демона из списка наблюдаемых
    -h, --help                   справка
    -v, --version                версия

| Файл | Назначение |
| --- | --- |
| `src/main.vala` | точка входа: блокировка единственного экземпляра, чтение настроек, список демонов, цикл GTK |
| `src/app.vala` | константы, пути каталогов, журнал |

| `src/utils.vala` | файловые операции, запуск процессов, действия файловых менеджеров, проверка автозапуска |
| `src/daemon.vala` | интерфейс демона: опрос с адаптивной задержкой, разбор вывода, монитор лога, start/stop |
| `src/indicator.vala` | иконка в панели, анимация занятости, меню состояния |
| `src/preferences.vala` | диалог настроек и список исключаемых каталогов |
| `src/notification.vala` | экранные уведомления |
| `tests/parse_test.vala` | тесты разбора вывода демона и конфигурации, собираются без GUI |
| `icons/`, `translations/`, `fm-actions/`, `ya-setup`, `Yandex.Disk-indicator-vala.desktop` | данные приложения: `prepare.sh` раскладывает их в каталог установки |
| `prepare.sh` | подготовка каталога данных (иконки, `ya-setup`, переводы, действия ФМ) |
| `debian/` | упаковка `.deb` |

## Файлы и каталоги

| Путь | Содержимое |
| --- | --- |
| `~/.config/yd-tools/yandex-disk-indicator.conf` | autostart, notifications, theme, fmextensions, daemons |
| `~/.config/yd-tools/yandex-disk-indicator.lock` | блокировка единственного экземпляра с PID |
| `~/.config/yd-tools/icons/{dark,light}` | пользовательские иконки, имеют приоритет над штатными |
| `~/.config/yd-tools/icons/readme` | описание формата пользовательских иконок |
| `~/.config/yandex-disk/config.cfg` | конфигурация демона: dir, auth, read-only, exclude-dirs |
| `/usr/share/yd-tools-vala` | данные: иконки, `ya-setup`, переводы, действия файловых менеджеров |

## Поведение

Статус демона берётся из вывода `yandex-disk status`, который запускается с
очищенным окружением (`env -i`), чтобы ключевые строки всегда были на английском.
Вывод в пользовательской локали запрашивается только для окна «Сообщение демона».

Опрос повторяется через 2 с при активной синхронизации и с растущей до 10 с
задержкой в покое; он не прекращается, чтобы остановка демона извне всё равно
обнаруживалась. Дополнительно за изменениями следит монитор файла
`.sync/cli.log` в каталоге синхронизации.

Команды `yandex-disk` выполняются в рабочем потоке, а результат передаётся в
основной цикл GTK, поэтому интерфейс не блокируется. Синхронно демон
останавливается только при выходе из индикатора, если включена опция
«Останавливать демон при закрытии индикатора».

Уведомления отправляются через интерфейс `org.freedesktop.Notifications` по
D-Bus, отдельная библиотека уведомлений не используется.

Двойной щелчок левой кнопкой по иконке в области уведомления открывает папку
синхронизации. Иконка показывается через StatusNotifier, если на шине сессии
запущен наблюдатель, и через системный лоток XEmbed иначе; двойной щелчок
поддерживает только лоток, так как в протоколе StatusNotifier такого события
нет — там папка доступна из меню.

Переводы берутся из домена `yandex-disk-indicator`: каталог `<данные>/locale`,
либо путь из переменной окружения `YD_LOCALEDIR`, либо `/usr/share/locale`.

## Сборка пакета

    make deb

Файлы пакета появляются в `build/deb/` внутри проекта (каталог задаётся
переменной `DEB_OUT`): основной `.deb`, пакет отладочных символов, `.changes`
и `.buildinfo`. Сборка идёт без подписи. Установка:

    sudo dpkg -i build/deb/yd-tools-vala_*.deb

Версия пакета берётся из константы `YD::APPVER` в `src/app.vala`: цель `deb`
проставляет её в верхнюю запись `debian/changelog`, поэтому версию достаточно
менять только в `src/app.vala`.

По окончании дерево очищается от подготовленного каталога `usr/` и
промежуточных результатов dpkg; `make clean` дополнительно удаляет `build/`
вместе с собранными пакетами.
